**Сучасна цифрова система управління бібліотекою** через Telegram з підтримкою мультиформатних книг, аудіокниг, AI-рекомендацій та персоналізованого досвіду читання.

---

## 🎯 Про проєкт

ReadLine - це повнофункціональний Telegram-бот для автоматизації бібліотечних процесів з інтеграцією штучного інтелекту. Бот забезпечує 24/7 доступ до каталогу книг, підтримує різні формати (PDF, EPUB, FB2, аудіо), використовує Google Gemini AI для персональних рекомендацій та надає зручний адаптивний інтерфейс як для читачів, так і для адміністраторів.

### Ключові переваги

- ✅ **Мультиформатність** - PDF, EPUB, FB2, MOBI, аудіокниги, онлайн-читання
- ✅ **AI-інтеграція** - Google Gemini 2.0 Flash для рекомендацій, OCR, генерації тегів
- ✅ **Розумний пошук** - fuzzy search, синоніми, автодоповнення, пошук за тегами
- ✅ **Аудіоплеєр** - вбудований плеєр з відстеженням прогресу, закладками, швидкістю
- ✅ **Персоналізація** - онбординг, адаптивні клавіатури, розумні нагадування
- ✅ **Модерація** - система відгуків з модерацією та автоматичним розрахунком рейтингів
- ✅ **Статистика** - детальна аналітика використання, популярності та поведінки користувачів
- ✅ **Оптимізація** - кешування, пагінація, індекси БД для швидкої роботикнигу: "Захар Беркут" (ID: 9)
✅ Додано книгу: "Енеїда" (ID: 10)
✅ Додано книгу: "Дракула" (ID: 11)

### Шари архітектури

#### 1. Presentation Layer (Інтерфейс)
- **Telegram Bot API** - взаємодія з користувачами
- **Клавіатури** - Inline та Reply клавіатури для навігації
- **Сцени** - багатокрокові діалоги для складних операцій

#### 2. Business Logic Layer (Бізнес-логіка)
- **Handlers** - обробка команд та callback queries
- **Scenes** - логіка багатокрокових процесів
- **Middleware** - авторизація, rate limiting, логування

#### 3. Data Layer (Дані)
- **Models** - CRUD операції з базою даних
- **Database Wrapper** - абстракція над SQLite
- **Cache** - in-memory кешування для продуктивності

#### 4. Utilities Layer (Утиліти)
- **Validation** - валідація вхідних даних
- **Logger** - структуроване логування
- **AI Helper** - інтеграція з Google Gemini
- **Notifications** - система сповіщень

### База даних (SQLite)

#### Таблиці

**books** - Каталог книг
```sql
- id, title, author, genre, description
- photo_file_id (Telegram file_id обкладинки)
- pdf_file_id, file_format (PDF, EPUB, FB2, MOBI)
- external_link (онлайн-читання)
- audio_file_id, audio_external_link, audio_duration, narrator
- rating, reviews_count, downloads_count
- is_available, created_at
```

**users** - Користувачі
```sql
- id, user_id, username, first_name, last_name
- has_completed_onboarding, favorite_genres
- created_at, last_active_at
```

**reviews** - Відгуки на книги
```sql
- id, book_id, user_id, user_name
- rating (1-5), comment
- is_published (модерація), created_at
```

**saved_books** - Збережені книги користувачів
```sql
- id, user_id, book_id, created_at
- UNIQUE(user_id, book_id)
```

**audio_chapters** - Розділи аудіокниг
```sql
- id, book_id, chapter_number, title
- file_id, duration, created_at
```

**listening_progress** - Прогрес прослуховування
```sql
- id, user_id, book_id, chapter_id
- position, total_listened
- last_listened_at, created_at
```

**tags** - Теги для книг
```sql
- id, name, created_at
```

**book_tags** - Зв'язок книг та тегів
```sql
- book_id, tag_id, created_at
- PRIMARY KEY (book_id, tag_id)
```

**admins** - Адміністратори
```sql
- id, user_id, username, created_at
```

**feedback_messages** - Зворотній зв'язок
```sql
- id, user_id, user_name, user_username
- message, status, admin_reply
- created_at, read_at
```

### Особливості реалізації

#### 1. Розумний пошук
Багаторівнева система пошуку:
- **Fuzzy search** - алгоритм Levenshtein distance для пошуку з помилками
- **Пошук за синонімами** - 10+ жанрів з альтернативними назвами
- **Автодоповнення** - підказки при введенні
- **Комбінований пошук** - поєднання всіх методів

#### 2. AI-рекомендації
Розумна система рекомендацій:
- **Аналіз поведінки** (40%) - збережені книги, завантаження, оцінки
- **Collaborative filtering** (30%) - схожі користувачі
- **Контекстні рекомендації** (30%) - час доби, день тижня
- **Fallback система** - топ книги → новинки → випадкові

#### 3. Валідація даних
Всі вхідні дані валідуються через `validation.ts`:
- Валідація даних книги (назва 2-200 символів, опис 10-500)
- Валідація відгуків (рейтинг 1-5, коментар)
- Валідація пошукових запитів (мінімум 2 символи)
- Валідація URL та телефонів

#### 4. Кешування та оптимізація
In-memory кешування для покращення продуктивності:
- Кешування жанрів (15 хвилин)
- Кешування топ книг (5 хвилин)
- Кешування новинок (5 хвилин)
- Пагінація (5-10 книг на сторінку)
- Індекси в БД для швидких запитів
- Автоматична очистка expired записів

#### 5. Rate Limiting
Захист від спаму та перевантаження:
- Обмеження частоти повідомлень (5 повідомлень/10 секунд)
- Обмеження частоти callback queries (10 запитів/10 секунд)
- Налаштовувані ліміти через константи

#### 6. Логування
Структуроване логування всіх подій:
- Логування помилок з контекстом
- Логування дій користувачів
- Логування адмін дій
- Логування database queries (debug режим)
- Логування AI запитів та відповідей

#### 7. Обробка помилок
Глобальна обробка помилок:
- `bot.catch()` - обробка помилок бота
- `unhandledRejection` - обробка необроблених промісів
- `uncaughtException` - обробка необроблених винятків
- Повідомлення користувачам про помилки
- Graceful shutdown для коректного завершення

#### 8. AI-інтеграція (Google Gemini 2.0 Flash)
Повна інтеграція з AI:
- **Для користувачів:**
  - Персональні рекомендації книг
  - Пошук за описом сюжету
  - Інформація про авторів та жанри
  - Відповіді на питання про літературу
- **Для адмінів:**
  - OCR обкладинок (Vision API)
  - Автоматичне визначення жанру
  - Генерація тегів (3-5 тегів)
  - Перевірка якості опису (0-100 балів)

#### 9. Адаптивні клавіатури
Оптимізація для різних пристроїв:
- **Мобільні** - великі кнопки, 2 в ряд
- **Планшети** - компактні кнопки, 3 в ряд
- **Десктопи** - inline клавіатури, 4 в ряд
- Збереження налаштувань в БД

#### 10. Розумні нагадування
Система персоналізованих сповіщень:
- Нагадування про нові книги в улюблених жанрах
- Нагадування про незавершені аудіокниги
- Налаштування частоти (щодня, раз на 4 дні, раз на тиждень)
- Можливість вимкнути сповіщення
