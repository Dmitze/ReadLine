Сучасна цифрова система управління полковою бібліотекою на основі Telegram-бота, яка дозволить автоматизувати процес обліку книг, обробки заявок та взаємодії з читачами.

## 📋 Огляд проекту

Створюємо сучасну цифрову систему управління полковою бібліотекою на основі Telegram-бота, яка дозволить автоматизувати процес обліку книг, обробки заявок та взаємодії з читачами.

## 🎯 Основні цілі та завдання

### **Головні цілі:**
- Створити зручний та інтуїтивний інтерфейс для користувачів
- Автоматизувати процес обліку книг та заявок
- Забезпечити простий механізм оновлення каталогу
- Зменшити адміністративне навантаження

### **Конкретні завдання:**
- 📚 Каталогізація 100+ існуючих книг
- 🤖 Автоматизація процесу замовлення
- 👥 Ефективне управління заявками
- 📱 Мобільність та доступність

## 🏗️ Архітектура системи

### **Технологічний стек:**
- **Backend**: Node.js + Telegraf framework
- **База даних**: SQLite (проста, не вимагає окремого сервера)
- **Хостинг**: VPS або хмарний хостинг (Render, Heroku)
- **Мова**: JavaScript/TypeScript

### **Компоненти системи:**

#### **1. Користувацький інтерфейс (Telegram Bot)**
- Інтерактивні меню та кнопки
- Спрощена навігація
- Мультимедійний контент (фото книг)

#### **2. Система управління контентом**
- Додавання нових книг
- Категоризація за жанрами
- Оновлення інформації

#### **3. Система заявок**
- Автоматичне сповіщення адміністратора
- Статуси заявок
- Історія видач

## ⚙️ Детальний опис функціоналу

### **Для читачів (військовослужбовців):**

#### **1. Реєстрація та початок роботи**
```
/start → Головне меню → Вибір дії
```

**Головне меню пропонує:**
- 🔍 Перегляд каталогу
- 📚 Пошук книг
- 📋 Мої заявки
- ℹ️ Допомога

#### **2. Перегляд каталогу книг**
- **Жанрова навігація** (художня література, військова, технічна тощо)
- **Списки книг** з фото обкладинок
- **Детальна інформація** про кожну книгу:
  - Фото обкладинки
  - Назва та автор
  - Жанр
  - Короткий опис
  - Статус доступності

#### **3. Система замовлення**
- **Проста форма заявки**:
  - Автоматичне заповнення даних книги
  - Введення ПІБ
  - Вибір підрозділу
  - Контактні дані
- **Миттєве сповіщення** адміністратора

#### **4. Особистий кабінет**
- Перегляд історії заявок
- Статуси поточних замовлень
- Список прочитаних книг

### **Для адміністратора:**

#### **1. Панель управління**
```
/admin → Адмін-панель з опціями:
```

**Основні функції адміністратора:**
- 👁️ Перегляд нових заявок
- ✅ Підтвердження видачі
- ❌ Відхилення заявок
- 📊 Статистика бібліотеки

#### **2. Система управління книгами**
- **Додавання нових книг** через інтуїтивний інтерфейс:
  - Назва та автор
  - Вибір жанру зі списку
  - Завантаження фото обкладинки
  - Опис книги
- **Редагування існуючих записів**
- **Відстеження доступності** книг

#### **3. Обробка заявок**
- **Список заявок** у реальному часі
- **Детальна інформація** про кожну заявку:
  - Дані читача (ПІБ, підрозділ)
  - Замовлена книга
  - Дата заявки
- **Швидкі дії** (підтвердити/відхилити)

## 🔄 Процеси та робочі потоки

### **Процес замовлення книги:**
1. Користувач обирає книгу з каталогу
2. Заповнює просту форму
3. Адміністратор отримує сповіщення
4. Адміністратор обробляє заявку
5. Користувач отримує підтвердження

### **Процес додавання нової книги:**
1. Адміністратор відкриває адмін-панель
2. Обирає "Додати книгу"
3. Заповнює інформацію через крокову форму
4. Завантажує фото обкладинки
5. Книга автоматично з'являється в каталозі
