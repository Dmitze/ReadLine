## 🎯 Функціонал

### Для користувача:

1. **Каталог → Підкасти**
   - Перегляд списку всіх підкастів
   - Відображення рейтингу та назви

2. **Картка підкасту**
   - Тема, опис, тривалість
   - Кількість прослуховувань
   - Рейтинг та кількість відгуків
   - Обкладинка (опціонально)

3. **Прослуховування**
   - Аудіо файл → відправляється безпосередньо
   - Посилання → відправляється URL
   - Архів → відправляється документ
   - Автоматичний підрахунок прослуховувань

4. **Відгуки**
   - Перегляд відгуків інших користувачів
   - Можливість залишити свій відгук (до реалізації)

### Для адміна:

1. **Додавання підкасту**
   - Wizard з 4 кроків
   - Підтримка 3 типів файлів
   - Можливість додати обкладинку (опціонально)
   - Попередній перегляд перед публікацією

2. **Управління**
   - Видалення підкастів (функція є, UI до реалізації)
