# 🔔 Система Сповіщень і Нагадувань (Notifications System)

## Як це працює

Бот має систему автоматичних персоналізованих сповіщень для користувачів. Вона нагадує їм про бота та інформує про цікаві пропозиції.

---

## 📋 Налаштування Сповіщень

### Де налаштовуються
**⚙️ Налаштування → 🔔 Сповіщення**

### Параметри налаштування:

```
Статус: ✅ Увімкнено / ❌ Вимкнено
Частота: 
  - 📅 Щодня (кожні 24 години)
  - 📆 Раз на 4 дні (кожні 96 годин)
  - 📅 Раз на тиждень (кожні 168 годин)
  - 🔕 Вимкнено (без сповіщень)
Час: 10:00 (за замовчуванням)
```

### Зберігання даних в БД
```sql
Таблиця: users
Колонки:
- notifications_enabled (1 = увімкнено, 0 = вимкнено)
- notification_frequency (daily, every_4_days, weekly, disabled)
- notification_time (HH:MM формат, напр. "10:00")
- last_notification_at (дата/час останнього сповіщення)
```

## ⏰ Як Працює Планувальник (Scheduler)

### Запуск
- Запускається при старті бота: `src/index.ts` (лінія 459)
- **Інтервал перевірки**: кожну годину (3600000 мс)

### Алгоритм

```javascript
startNotificationScheduler(bot)
  ↓
Кожну годину:
  1. Отримати всіх користувачів з ввімкненими сповіщеннями
  2. Розділити на батчі по 10 користувачів
  3. Для кожного користувача:
     - Перевірити, чи пройшов час з останнього сповіщення
     - Якщо так → відправити персоналізоване сповіщення
  4. Затримка 2 сек між батчами (щоб не перевантажити бот)
```

### Умовна логіка (shouldSendNotification)

```
Якщо вимкнено? → НЕ відправляти
Якщо частота = disabled? → НЕ відправляти

Перевірити часовий проміжок:
  daily (щодня)         → якщо пройшло ≥ 24 години
  every_4_days (раз на 4) → якщо пройшло ≥ 96 годин
  weekly (щотижнево)    → якщо пройшло ≥ 168 годин
```

## 🤖 Персоналізовані Сповіщення

Бот має **5 типів персоналізованих сповіщень** та вибирає повідомлення в цьому порядку пріоритету:

### 1️⃣ **Нові книги в улюблених жанрах** (найпопулярніше)
```
👋 Привіт, Дмитро!

📚 Є новинка! Додано 3 нові книги в твоїх улюблених жанрах.

Хочеш подивитися? 👀
```

**Як це працює:**
- Перевіряє сохранені улюблені жанри користувача
- Ищет книги, додані за останні 7 днів
- Якщо знайдено → відправити це сповіщення

### 2️⃣ **Незавершена аудіокнига**
```
👋 Привіт, Дмитро!

🎧 Ти почав слухати "Серцеве клопотання".

Продовжимо? 🎵
```

**Як це працює:**
- Перевіряє, чи є в користувача збережена аудіокнига
- Якщо є → нагадує про неї

### 3️⃣ **Нагадування про неактивність** (якщо юзер давно не заходив)
```
👋 Давно не бачилися, Дмитро!

📚 У нас є багато цікавих книг.
Може час знайти щось нове для читання? 📖
```

**Як це працює:**
- Перевіряє `last_active_at` користувача
- Якщо не заходив > 7 днів → відправити це сповіщення

### 4️⃣ **Топ рейтингові книги цього місяця** ⭐
```
⭐ Дмитро, погляньте на це!

🏆 У нас з'явилися найкраще оцінені книги цього місяця.

Вже читаєш щось круте? 🔥
```

**Як це працює:**
- Шукає найкраще оцінені книги з останнього місяця
- Якщо знайдено → інформує про популярні видання
- Мотивує читати топові книги

### 5️⃣ **Мотиваційне сповіщення про читання** 💪
```
💪 Привіт, Дмитро!

📖 Ти не читав цього тижня.

Кожна сторінка - це нова історія. Почнемо? ✨
```

**Як це працює:**
- Перевіряє, скільки книг додав користувач до бібліотеки за останній тиждень
- Якщо нічого не додав → надсилає мотиваційне сповіщення
- Спонукає повернутися до читання

### Якщо нічого не підходить
- **Не відправляти** (повертає `null`)

## 🔧 Як додати нове персоналізоване сповіщення

### Крок 1: Додайте логіку в `getPersonalizedNotification()`

Відкрийте `src/utils/notifications.ts` і додайте вашу умову **перед `return null`** (в кінці функції):

```javascript
// Приклад: перевірка если користувач давно не читав
const booksReadThisWeek = await new Promise<{ count: number } | undefined>((resolve, reject) => {
  db.get(
    `
    SELECT COUNT(*) as count
    FROM saved_books
    WHERE user_id = ?
    AND created_at > datetime('now', '-7 days')
  `,
    [userId],
    (err, row: { count: number } | undefined) => {
      if (err) reject(err);
      else resolve(row);
    }
  );
});

if (booksReadThisWeek && booksReadThisWeek.count === 0) {
  return `💪 Привіт, ${firstName}!\n\nТи не читав цього тижня.\nКожна сторінка - це нова історія. Почнемо? ✨`;
}
```

### Крок 2: Кнопки будуть однакові

Кнопки в усіх сповіщеннях однакові, тому змінювати нічого не потрібно:

```javascript
await bot.telegram.sendMessage(userId, message, {
  reply_markup: {
    inline_keyboard: [
      [{ text: '📖 Переглянути новинки', callback_data: 'view_new_books' }],
      [{ text: '🎲 Випадкова книга', callback_data: 'random_book' }],
      [{ text: '⚙️ Налаштування сповіщень', callback_data: 'notification_settings' }],
    ],
  },
});
```

## ⚠️ Важливі Моменти

### 1. **Без спаму**
- Частота перевіряється перед відправленням
- Якщо час не настав → сповіщення не відправляється
- Затримка між батчами (2 сек) щоб не перевантажити Telegram API

### 2. **Персоналізація**
- Використовує справжні дані користувача (ім'я, жанри, прогрес)
- Не просто копія для всіх

### 3. **Контроль користувача**
- Можна вимкнути в налаштуваннях
- Можна змінити частоту

### 4. **Batch Processing**
- 10 користувачів одночасно (затримка 2 сек)
- Уникає deadlock в БД
- Рівномірно розподіляє навантаження

## 📞 Основні Функції в Коді

**`src/utils/notifications.ts`:**
- `shouldSendNotification(userId)` - перевіряє чи прийшов час сповіщення
- `getPersonalizedNotification(userId)` - формує персоналізоване повідомлення (5 типів)
- `sendNotification(bot, userId)` - надсилає сповіщення в Telegram
- `getUserNotificationSettings(userId)` - отримує налаштування користувача
- `setUserNotificationSettings(settings)` - зберігає налаштування
- `startNotificationScheduler(bot)` - запускає планувальник (кожну годину)
- `stopNotificationScheduler(interval)` - зупиняє планувальник

## 🔍 Резюме
