## 🎯 Починаєте знайомитися з ботом?

### 5 хвилин для користувачей:

1. Прочитайте [USER_GUIDE.md — Головне меню](./USER_GUIDE.md#-головне-меню)
2. Спробуйте натиснути **📖 КАТАЛОГ**
3. Пошукайте улюблену книгу
4. Натисніть **⭐ ОЦІНИТИ** та залиште відгук
5. Включіть **🔔 СПОВІЩЕННЯ** в налаштуваннях

### 10 хвилин для адміністраторів:

1. Прочитайте [ADMIN_GUIDE.md — Налаштування доступу](./ADMIN_GUIDE.md#-налаштування-доступу-адміністратора)
2. Запустіть `/admin` в чаті
3. Натисніть **➕ ДОДАТИ КНИГУ**
4. Слідуйте 9-кроковій формі
5. Перевірте нову книгу в каталозі

## 🔍 Пошук у документації

Якщо вам потрібна інформація про конкретну тему, скористайтесь **Ctrl+F** (Command+F на Mac) щоб знайти потрібний розділ:

### Популярні пошукові терміни:

- `Додавання книги` → ADMIN_GUIDE.md

- `Промокод` → ADMIN_GUIDE.md або USER_GUIDE.md
- `AI` → USER_GUIDE.md
- `Модерація` → ADMIN_GUIDE.md
- `Аудіокнига` → USER_GUIDE.md
- `Статистика` → ADMIN_GUIDE.md

## ⚠️ Що робити при проблемах?

### Користувач:
1. Перевірте [USER_GUIDE.md — Часті запитання](./USER_GUIDE.md#-часті-запитання)
2. Спробуйте `/start` для перезапуску
3. Напишіть **📞 ЗВОРОТНІЙ ЗВ'ЯЗОК** адміністратору

### Адміністратор:
1. Перевірте [ADMIN_GUIDE.md — Вирішення проблем](./ADMIN_GUIDE.md#-часті-помилки-та-їх-вирішення)
2. Переглядайте логи в `logs/` папці
3. Проконсультуйтеся з розробником
