# 🛠️ Керівництво адміністратора ReadLine

## 🎯 Для адміністраторів та модераторів

Це керівництво описує як керувати ботом, додавати контент, модерувати матеріал та аналізувати статистику.

> ⚠️ **Важливо:** Ви повинні бути авторизовані як адміністратор (User ID в .env)

---

## 🔐 Налаштування доступу адміністратора

### Першого запуску (Initial Setup)

1. **Отримайте ваш User ID:**
   - Знайдіть бота **@userinfobot** в Telegram
   - Натисніть /start і скопіюйте ваш ID (формат: 123456789)

2. **Встановіть ADMIN_ID в .env:**
   ```env
   ADMIN_ID=123456789
   ```

3. **Кілька адміністраторів:**
   ```env
   ADMIN_ID=123456789,987654321,111222333
   ```

4. **Запустіть бота:**
   ```bash
   npm run build
   npm start
   ```

5. **Перевірте доступ:**
   - Відкрийте чат з ботом
   - Введіть `/admin`
   - Ви повинні побачити адмін-панель

### Якщо доступ не надається:
- Перевірте ваш User ID
- Перевірте формат в .env (без пробілів)
- Перезапустіть бота
- Закрийте та повторно відкрийте чат

## ➕ Додавання книги (9 кроків)

### Команда для запуску: `/admin` → **➕ ДОДАТИ КНИГУ**

Це 9-крокова форма з AI-помічником:

### **Крок 1️⃣: Назва та автор**

```
Введіть назву книги та автора:
(Приклад: "Война и мир" Лев Толстой)
```

**AI допоміжник запропонує:**
- Поточна рейтинг книги (якщо вона існує)
- Кількість істотних видань
- Альтернативні назви

### **Крок 2️⃣: Жанр**

Виберіть один жанр зі списку (24+ жанрів):

```
📚 Все жанры
├─ Фантастика
├─ Фентезі
├─ Історичні романи
├─ Детектив
├─ Любовний романс
├─ Проза
├─ Поезія
├─ Біографія
├─ Саморозвиток
├─ Наукова література
├─ Дитяча
├─ Навчальна
└─ ... (24 жанри всього)
```

**Як вибрати:**
1. Натисніть на інтересуючий жанр
2. Система запропонує 2-3 аналогічні варіанти
3. Підтвердіть вибір

### **Крок 3️⃣: Опис**

```
Введіть опис книги (до 500 символів):
```

**AI допоміжник:**
- Виправляє граматичні помилки
- Вирівнює довжину опису
- Пропонує додати цікаві деталі
- Рекомендує ключові слова для пошуку

**Приклад хорошого опису:**
> Епічна історія про вірність, любов та смерть в період наполеонівських воєн. Толстой змішує інтимні портрети облич з панорамним поглядом на історію. Роман охоплює понад 600 років російської історії.

### **Крок 4️⃣: Фото обкладинки**

```
Завантажте фото обкладинки книги:
(Форма: JPEG, PNG | Розмір: не більше 5 MB)
```

**Рекомендації:**
- Вертикальна орієнтація (висота > ширини)
- Чіткий образ без водяних знаків
- Мінімум 300x400 пікселів

**AI обробка:**
- Система автоматично оптимізує розмір
- Перевіряє якість
- Пропонує використати інше фото якщо погане

### **Крок 5️⃣: Вибір формату**

Виберіть спосіб розповсюдження:

```
📄 PDF/EPUB/FB2/MOBI
  └─ Файл буде завантажено в Telegram
  └─ Користувачі завантажуватимуть звідси
  
🌐 ОНЛАЙН ПОСИЛАННЯ
  └─ Google Drive, Dropbox або власний сервер
  └─ Користувачі читатимуть онлайн
  
🎧 АУДІОКНИГА
  └─ MP3 файл з розділами
  └─ Вбудований плеєр з сохранением прогресу
  
🎙️ ПОДКАСТ
  └─ Контент з епізодами
  └─ Керування розділами та метаданими
  
🔀 КОМБІНОВАНО
  └─ Зразу кілька форматів (текст + аудіо)
  └─ Користувач вибирає
```

**Виберіть один або кілька варіантів**

### **Крок 6️⃣: Завантаження файлу або посилання**

Залежно від вибору формату:

#### 📄 **Для PDF/EPUB файлів:**
```
Завантажте файл:
(Формати: .pdf, .epub, .fb2, .mobi)
(Максимум: 500 MB)
```

**Система:**
- Перевіряє файл на корупцію
- Отримує метаданих (кількість сторінок)
- Показує попередній перегляд

#### 🌐 **Для онлайн посилань:**
```
Введіть посилання на книгу:
(Приклади:
- https://drive.google.com/file/d/...
- https://www.dropbox.com/s/...
- https://myserver.com/books/...)
```

**Перевірка посилання:**
- Система перевіряє доступність
- Тестує завантажувальність
- Показує помилку якщо посилання мертве

#### 🎧 **Для аудіокниги:**
```
1. Завантажте MP3 файли розділів
2. Систем автоматично розпізнає розділи:
   - 01-Chapter.mp3 → Розділ 1
   - 02-Chapter.mp3 → Розділ 2
   - ...
```

### **Крок 7️⃣: Додавання тегів**

```
Додайте теги для книги:
(Виберіть з пропозицій або введіть свої)

Доступні теги:
✓ Класика
✓ Любовний роман
✓ Детектив
✓ Фентезі-світ
✓ Сучасна проза
... (24+ тегу)
```

**Як додати теги:**
1. Натисніть на тег щоб додати його
2. Введіть новий тег якщо потрібно
3. Видаліть тег натиском **❌**

**AI пропозиції:**
- На основі назви та опису
- Показує теги які використовувати інші для подібних книг
- Рекомендує найбільш релевантні

### **Крок 8️⃣: Перегляд та редагування**

```
📖 НАЗВА: War and Peace
✍️ АВТОР: Leo Tolstoy
📚 ЖАНР: Історичні романи
⭐ ОПИС: Epic tale of love, war and death...
📷 ОБКЛАДИНКА: [зображення завантажено ✓]
📄 ФОРМАТ: PDF (загальний розмір: 12.5 MB)
🏷️ ТЕГИ: Класика, Історія, Вікторіанська епоха
```

**Можете повернутися і редагувати будь-яке поле:**
- Натисніть на поле щоб змінити
- Система запропонує редактор для цього поля
- Повернеться до перегляду

### **Крок 9️⃣: Публікація**

```
✅ ВСЕ ГОТОВО!

Книга буде опублікована та доступна
для всіх користувачів.

[✅ ОПУБЛІКУВАТИ]  [❌ СКАСУВАТИ]
```

**При публікації:**
- Книга додається до каталогу
- Користувачі отримають сповіщення про новинку
- Книга з'являється в фільтрі "Новинки"
- AI переіндексує для пошуку

## ⚠️ Часті помилки та їх вирішення

### В: Не можу запустити адмін-панель

**О:** Перевірте:
1. Чи вписаний ваш User ID в .env?
2. Чи немає пробілів: `ADMIN_ID=123456789`
3. Чи перезапустили бота після змін?
4. Введіть `/admin` в приватному чаті з ботом

### В: Файл завантажується але не відкривається

**О:** Причини:
- Файл корупцій або неправильного формату
- Надто великий файл (>500 MB)
- Посилання мертве

**Вирішення:**
- Перевірте файл на локальному комп'ютері
- Конвертуйте у підтримуваний формат (PDF/EPUB)
- Покроково завантажуйте більші файли

### В: Користувачи не бачать мою нову книгу

**О:** Причини:
- Книга не опублікована (забули натиснути ✅)
- Книга приватна (статус для адміністраторів)
- Кеш не оновився (чекайте 5 хвилин)

**Вирішення:**
1. Перевірте статус книги в /admin
2. Переконайтесь що це PUBLIC
3. Відправте користувачам сповіщення про новинку

### В: Промокод не працює

**О:** Причини:
- Код закінчився (дата просрочена)
- Вичерпана кількість використань
- Код не опублікований (статус)

**Вирішення:**
1. Перевірте дату в статистиці промокоду
2. Тестуйте сам код перед надіслан користувачам
3. Продовжте дату якщо потрібно
