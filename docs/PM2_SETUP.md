# PM2 Setup for ReadLine Bot

## Что это?

**PM2** - это Process Manager для Node.js приложений. Он позволяет:
- ✅ Автоматически перезагружать приложение при крахе
- ✅ Поддерживать приложение в работе 24/7
- ✅ Перезагружать приложение из админ-панели
- ✅ Просматривать логи и мониторить использование памяти
- ✅ Запускать приложение при старте сервера

## Установка PM2

### Шаг 1: Установить PM2 глобально

```bash
npm install -g pm2
```

### Шаг 2: Собрать проект

```bash
npm run build
```

### Шаг 3: Запустить бота через PM2

```bash
pm2 start ecosystem.config.js
```

### Шаг 4: Сохранить конфиг PM2

```bash
pm2 save
```

### Шаг 5: Настроить автозагрузку при перезагрузке сервера (Linux)

```bash
pm2 startup systemd -u your-username --hp /home/your-username
pm2 save
```

Или на macOS:

```bash
pm2 startup launchd -u your-username --hp /Users/your-username
pm2 save
```

## Полезные PM2 команды

```bash
# Просмотреть статус всех процессов
pm2 list

# Просмотреть логи бота
pm2 logs ReadLine

# Просмотреть логи последних 100 строк
pm2 logs ReadLine --lines 100

# Просмотреть статистику в реальном времени
pm2 monit

# Остановить бота
pm2 stop ReadLine

# Перезагрузить бота (graceful restart)
pm2 restart ReadLine

# Удалить бота из PM2
pm2 delete ReadLine

# Сохранить список процессов
pm2 save

# Восстановить процессы при старте
pm2 resurrect
```

## Как работает кнопка "Перезавантажити бота" в админ-панели

Когда админ нажимает кнопку "🔄 Перезавантажити бота":

1. Бот показывает сообщение о перезагрузке
2. Бот завершает процесс с exit кодом 1
3. **PM2 видит что процесс завершился** и автоматически его перезагружает
4. Бот запускается заново и готов к работе

## Если PM2 не установлен

Если вы запустили бота без PM2:

```bash
npm start
```

Кнопка "Перезавантажити бота" просто выключит бот. Вам нужно будет:
1. Вручную перезапустить бот командой `npm start`
2. Или установить PM2 (рекомендуется)

## Проверка что PM2 работает

```bash
# Список активных процессов
pm2 list

# Вывод должен показать ReadLine как "online"
```

## Troubleshooting

### Процесс не перезагружается

```bash
# Проверить логи ошибок
pm2 logs ReadLine

# Убедиться что processo запущен
pm2 list
```

### PM2 не сохраняется при перезагрузке сервера

```bash
pm2 startup
pm2 save
```

### Очистить старые процессы

```bash
# Удалить все процессы
pm2 kill

# Перезагрузить с нуля
pm2 start ecosystem.config.js
pm2 save
```

## Продвинутые настройки

Изменить `ecosystem.config.js` для своих нужд:

- `max_memory_restart` - перезагрузить если память превысит это значение
- `watch` - включить для автоматической перезагрузки при изменении файлов (для разработки)
- `instances` - количество процессов (используйте 'max' для всех CPU ядер)

## Windows пользователи

Если используете Windows, установите PM2 как Windows сервис:

```bash
npm install -g pm2-windows-startup
pm2 install pm2-windows-startup
pm2 start ecosystem.config.js
pm2 save
```

Или просто используйте WSL2 с Linux командами выше.

---

**Главное правило:** Всегда используйте PM2 для production! Это обеспечит стабильность и надёжность бота.
