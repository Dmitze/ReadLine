# 📋 Аналіз системи замовлення фізичних книг

## 🎯 Мета

Створити спрощену систему замовлення фізичних книг, де:
- Адмін при додаванні книги вказує чи є вона фізично в наявності
- Користувач бачить статус наявності в описі книги
- Користувач може замовити книгу через просту форму (4 поля)
- Без складної системи статусів та повернень

### 4. Scene замовлення книги

**Файл:** `src/scenes/bookOrderScene.ts` (новий)

**Структура:**

```typescript
Scene State:
{
  bookId: number;
  bookTitle: string;
  bookAuthor: string;
  full_name?: string;
  callsign?: string;
  unit?: string;
  phone?: string;
  step: string;
}

Кроки:
1. ENTER - Привітання та інформація про книгу
2. Крок 1 - ПІБ
3. Крок 2 - Позивний
4. Крок 3 - Підрозділ
5. Крок 4 - Номер телефону
6. Підтвердження
7. LEAVE - Відправка замовлення
```

**Приклад ENTER:**
```typescript
bookOrderScene.enter(async (ctx) => {
  const { bookId } = ctx.scene.state;
  const book = await getBookById(bookId);
  
  if (!book || !book.is_physically_available) {
    await ctx.reply('❌ Ця книга недоступна для замовлення');
    return ctx.scene.leave();
  }
  
  ctx.scene.state.bookTitle = book.title;
  ctx.scene.state.bookAuthor = book.author;
  
  await ctx.reply(
    '📋 <b>ЗАМОВЛЕННЯ КНИГИ</b>\n\n' +
    `📖 Книга: ${book.title}\n` +
    `👤 Автор: ${book.author}\n\n` +
    '━━━━━━━━━━━━━━━━━━━\n\n' +
    'Для замовлення книги заповніть контактні дані.\n' +
    'Адміністратор зв\'яжеться з вами для узгодження деталей.\n\n' +
    '👤 <b>КРОК 1/4: ПІБ</b>\n\n' +
    'Введіть ваше повне ім\'я:\n' +
    '💡 <i>Приклад: Іваненко Іван Іванович</i>',
    { parse_mode: 'HTML' }
  );
  
  ctx.scene.state.step = 'full_name';
});
```

async function showBookOrders(ctx) {
  const orders = await getAllBookOrders();
  
  let message = '📋 <b>ЗАМОВЛЕННЯ КНИГ</b>\n\n';
  message += `Всього замовлень: ${orders.length}\n\n`;
  message += '━━━━━━━━━━━━━━━━━━━\n\n';
  
  orders.forEach((order, index) => {
    message += `${index + 1}. 📖 ${order.book_title}\n`;
    message += `   👤 ${order.full_name} (${order.callsign})\n`;
    message += `   🏢 ${order.unit}\n`;
    message += `   📞 ${order.phone}\n`;
    message += `   📅 ${formatDate(order.created_at)}\n\n`;
  });
  
  const buttons = orders.map(o => [
    Markup.button.callback(
      `#${o.id} - ${o.book_title}`,
      `admin_view_order_${o.id}`
    )
  ]);
  
  buttons.push([
    Markup.button.callback('🔄 Оновити', 'admin_refresh_orders'),
    Markup.button.callback('⬅️ Назад', 'admin_menu')
  ]);
  
  await ctx.reply(message, {
    parse_mode: 'HTML',
    reply_markup: Markup.inlineKeyboard(buttons).reply_markup
  });
}
