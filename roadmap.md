# Дорожня карта проекту ReadLine (Telegram бот для бібліотеки)

## Загальна інформація
Проект ReadLine - це Telegram-бот для управління полковою бібліотекою, розроблений з використанням TypeScript та фреймворку Telegraf.

## Технічні вимоги

### Мова програмування
- TypeScript (основна мова розробки)
- JavaScript (для сумісності)

### Фреймворки та бібліотеки
- Telegraf (фреймворк для розробки Telegram-ботів)
- SQLite (система управління базами даних)
- dotenv (для управління змінними оточення)

### Інструменти розробки
- Node.js (середовище виконання)
- npm (менеджер пакетів)
- TypeScript compiler (tsc)
