## 🆘 Розв'язання проблем

### Бот не запускається

```bash
# Перевірте .env
cat .env

# Перевірте валідність
npm run build
```

### Помилка "ADMIN_ID must be numeric"

Виправте формат:
```env
ADMIN_ID=906087418,547751718  # ✅ Правильно
ADMIN_ID=906087418, 547751718 # ✅ Також правильно (з пробілами)
```

### Redis не підключається

```bash
# Запустіть Redis
docker run -d -p 6379:6379 redis:latest

# Або через Docker Compose
docker-compose up -d
```
