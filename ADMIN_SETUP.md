# 🔐 Налаштування адміністраторів

## Як налаштувати кількох адміністраторів у ReadLine

### Формат ADMIN_ID у .env

ADMIN_ID підтримує вказання кількох User ID через кому:

#### ✅ Правильні формати:

```env
# Один адміністратор
ADMIN_ID=906087418

# Кілька адміністраторів (без пробілів)
ADMIN_ID=906087418,547751718,123456789

# Кілька адміністраторів (з пробілами)
ADMIN_ID=906087418, 547751718, 123456789

# Змішаний формат (з деякими пробілами)
ADMIN_ID=906087418,547751718, 123456789
```

#### ❌ Неправильні формати:

```env
# НЕ допускається: не-числові значення
ADMIN_ID=admin1,admin2

# НЕ допускається: порожні значення
ADMIN_ID=906087418,,547751718

# НЕ допускається: спеціальні символи (крім коми)
ADMIN_ID=906087418|547751718
```

## Крок за кроком

### 1️⃣ Отримайте User ID всіх адміністраторів

В Telegram:
1. Відкрийте `@userinfobot`
2. Надішліть `/start`
3. Бот надасть вам ваш User ID
4. Повторіть для кожного адміністратора

**Приклад:**
```
Адміністратор 1: 906087418
Адміністратор 2: 547751718
```

### 2️⃣ Оновіть .env файл

```bash
# Відкрийте .env текстовим редактором
nano .env
# або
code .env
```

Встановіть ADMIN_ID:

```env
ADMIN_ID=906087418,547751718
```

### 3️⃣ Перебудуйте та запустіть

```bash
# Перебудуйте проект
npm run build

# Ініціалізуйте адмінів в базі даних
npm run init-admin

# Запустіть бота
npm start
```

### 4️⃣ Перевірте роботу

Кожен адміністратор повинен мати доступ до:
- Команди `/admin` — відкривання адмін-панелі
- Функції додавання книг
- Модерації відгуків
- Перегляду статистики

## 📝 Система адміністраторів

### Як це працює

1. **Ініціалізація при запуску**
   - При виконанні `npm run init-admin` всі ID з ADMIN_ID додаються в базу даних
   - Якщо адмін вже існує, він не буде додано повторно

2. **Перевірка прав**
   - При натиску на `/admin` система перевіряє базу даних
   - Якщо користувач є адміністратором → доступ дозволено
   - Якщо ні → видається помилка

3. **Динамічне додавання нових адмінів**
   - Можна додавати нових адмінів через базу даних
   - Без необхідності перезавантажувати бот

## 🐛 Розв'язання проблем

### Помилка: "ADMIN_ID must be numeric IDs separated by commas"

**Причина:** ADMIN_ID має неправильний формат

**Рішення:**
```env
# ❌ Неправильно
ADMIN_ID=906087418, 547751718,

# ✅ Правильно
ADMIN_ID=906087418,547751718
```

### Помилка: "UNIQUE constraint failed: admins.user_id"

**Причина:** Адмін вже існує в базі даних

**Рішення:** Це нормально. Просто ігноруйте помилку або видаліть дублікати з БД:

```bash
# Видаліть старих адмінів
rm database/library.db

# Перебудуйте та переініціалізуйте
npm run build
npm run init-admin
npm start
```

### Помилка: "У вас немає доступу до адмін-панелі"

**Причина:** Ваш User ID не у списку адмінів

**Рішення:**
1. Перевірте ваш ID через `@userinfobot`
2. Додайте ID в ADMIN_ID
3. Виконайте `npm run init-admin`
4. Перезапустіть бот

## 📊 Управління адмінами через код

Якщо потрібно динамічно працювати з адмінами без перезапуску:

```typescript
// Додати адміна
import { addAdmin } from './src/database/models';
await addAdmin(123456789, 'admin');

// Перевірити чи є адміном
import { isAdmin } from './src/database/models';
const isUserAdmin = await isAdmin(123456789);

// Отримати всіх адмінів
import { getAllAdmins } from './src/database/models';
const allAdmins = await getAllAdmins();
```

## 🔄 Часті операції

### Додати нового адміністратора

1. Оновіть `.env`:
```env
ADMIN_ID=906087418,547751718,999888777
```

2. Запустіть:
```bash
npm run init-admin
npm start
```

### Видалити адміністратора

1. Отримайте доступ до БД (SQLite Browser)
2. Видаліть запис з таблиці `admins`
3. Перезапустіть бот

### Змінити адміністраторів без перезавантаження

Редагуйте таблицю `admins` напряму в SQLite.
